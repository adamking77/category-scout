# Corpus Reference — where the doctrine comes from

Every rule in this suite should be traceable to a source. This file is the citation map.

## Evidence chain

1. **ND Research Foundation** (IntelliZen project id 7) — the primary research base for the ND tool suite. Cases:
   - `case-2026-001` — PDA: what works and what backfires
   - `case-2026-002` — ADHD: executive function, motivation, and where tools fail
   - `case-2026-003` — autistic burnout: patterns, triggers, recovery
   - `case-2026-004` — ND people using AI: what fails, what they've adapted
   - `case-2026-005` — ND productivity frameworks: what has actually lasted
2. **docs/nd-research-synthesis.md** (in this repo) — the bridge between that research and the build. Contains the six in-repo non-negotiables and the stable principles.
3. **ND-Process-Framework.md** (in this repo) — the suite methodology: invitation-based, bursts beat schedules, dead zones protected, not-doing list, plain language.
4. **Lindsey Mackereth / Compression Framework** — spine-finder's source method. The team references a deeper corpus (the three gates: bored / confused / heavy / panicked; changed-baseline capacity; could/should/want; lanes and closed doors; room safety; seasons-not-sprints; interest half-life; the 15+8 non-negotiables list).
