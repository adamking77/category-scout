# Design a Process for One Goal — how to use this safely

## What this is

Takes one goal and your ND profile and builds a working process organized by how you feel, not by a calendar. Moves are triggered by conditions ("when you have 30 minutes and low energy") instead of days of the week. Built by GoKart Studio for neurodivergent founders.

## The rules it follows

- No schedules. No streaks. No completion scores.
- No fake urgency. It will never recommend deadlines or countdowns as a way to get moving.
- It will never tell you to just start.
- It defends one to three lanes you choose. Everything else is a closed door, and closing a door is allowed to hurt a little. That's the grief step, and it's part of the design.
- Quiet periods are planned rest, not failure. Your dead zones are protected.

## How to run it

1. Build your context profile first (the "Build your context profile" skill). The process gets much better with it.
2. Install this skill and start with "design a process for [goal]."
3. Give it a real, visible success signal: "what would count as real progress you could point to?"
4. Take the process file it writes. Your agent runs from it at every session.

## If the agent breaks the contract

If the process starts feeling like an obligation machine, reset it with any of these:

- "That's a demand. Reframe as an invitation or drop it."
- "That's a deadline. This process does not use deadline pressure."
- "That's catch-up framing. I am not behind."
- "That's a hard block. Close the door with the grief step instead."

You can always say not today. That is a designed outcome, not a failure.
