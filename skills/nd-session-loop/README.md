# Run a Session — how to use this safely

## What this is

A steady presence at the door of your work sessions. At the start, it checks in and surfaces exactly one move that fits how you actually feel. At the end, it captures what happened and updates your process. Built by GoKart Studio for neurodivergent founders.

## The rules it follows

- No streaks. No completion scores. No daily minimums.
- "Not today" is a complete answer. It accepts it without a follow-up.
- It will never tell you to just start. If you're stuck, it asks what kind of stuck: bored, confused, heavy, or panicked, and matches the unlock.
- Quiet periods are planned rest, not staleness. When you come back, nothing is owed.
- Reflection is for learning what helps, not for grading you.

## How to run it

1. Build a context profile and design a process first (the other two skills).
2. Install this skill and start any session with "start a session."
3. Answer the check-in honestly. One move appears. Do that or decline it.
4. End with "wrap up" when you're done. The reflection takes two minutes.

## If the agent breaks the contract

If the session starts feeling like a scoreboard or a guilt trip, reset it with any of these:

- "That's a streak question. This skill does not track streaks."
- "That's catch-up framing. I was away and nothing is owed."
- "That's just-start pressure. Match my gate instead."
- "That's grading me. Reflection is for learning."

You can always say not today, and the session closes cleanly. That is the design, not a loophole.
