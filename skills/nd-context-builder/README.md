# Build Your Context Profile — how to use this safely

## What this is

A guided interview that turns how you actually work into a profile file you own. You paste that file into any AI you use, and it stops treating you like a generic user. Built by GoKart Studio for neurodivergent founders.

## The rules it follows

- It will never diagnose you. If you ask "am I ADHD?", it will describe what you noticed instead of naming you.
- It will never push. No streaks, no "you missed this," no daily minimums.
- It will never tell you to just start.
- Your words are kept. The profile uses your language, not clinical labels.
- Trait labels are treated as working labels you chose, not verdicts.

## How to run it

1. Install the skill into your agent (Claude Code, Codex, or any tool that loads SKILL.md files).
2. Start with "build my context profile." Answer one question at a time. Skip anything you want.
3. Take the profile file it writes and paste it into any AI as part of your setup.
4. Update it whenever something changes. It is a living document, not a one-time form.

## If the agent breaks the contract

If the agent starts diagnosing you, pushing you, praising your capability to get you moving, or going silent on you, reset it with any of these:

- "That's diagnosing me. Hold multi-engine uncertainty instead."
- "That's a demand. Offer an invitation or nothing."
- "That's pushing. Accept what I actually said."
- "You went silent. Tell me what's happening."

You can always stop and walk away. `Not today` is a complete answer.
